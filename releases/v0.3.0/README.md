# ClassLive 0.3.0

下载 [ClassLive-0.3.0.apk](ClassLive-0.3.0.apk)。这是使用原有本地签名的归档包，可以覆盖归档版 0.1.0 / 0.2.0；不要先卸载，否则会删除应用私有文字与配置。

本版新增本地驱动的最高 +12 dB 自动增益、停顿期间背景估计、输出音量提示、麦克风输入模式选择，以及不调用 API 的 15 秒原声/处理后 A/B 回听测试。

打开设置，点击“本地收音测试”，比较同一段英语的原声与处理后声音。返回设置后保存满意的选项。所有测试音频只在内存中保留，不上传、不写文件。

17 项音频/导出模拟场景和持久化/迁移测试通过；APK 已验证 v2/v3 签名及与 0.2.0 的证书一致性。真实课堂识别效果和 vivo 回听界面尚未验证。

详细更新见根目录 [CHANGELOG.md](../../CHANGELOG.md)。对应源码见 [ClassLive-0.3.0-source.zip](ClassLive-0.3.0-source.zip)；摘要见 [SHA256SUMS](SHA256SUMS)。源码包不包含签名私钥或 API 密钥。
