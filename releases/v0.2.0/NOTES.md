# ClassLive 0.2.0

温和自动音量优化、持续收音异常提示、多课堂记录与补译。TXT 改为明确的“生成 TXT”按钮，支持双语／英文／中文，只有用户点击时导出。

保持保守默认：系统轻降噪关闭，前台收音，无原始音频保存，无自动重连回补。

APK：`ClassLive-0.2.0.apk`，应用 ID `com.yeezi.classlive`，versionCode 2，Android 8.0 及以上。与 0.1.0 签名相同，可覆盖升级；不要先卸载。

通过构建、签名、音频模拟及记录编码测试。尚未做 vivo 真机或真实 API 联调。详见根目录 README 和 CHANGELOG。
