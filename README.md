# ClassLive 课堂翻译 · Android 0.3.0

手机麦克风 → AssemblyAI 实时英语识别 → DeepSeek 中文翻译。Android 8.0 及以上。

## 安装

下载 [ClassLive-0.3.0.apk](releases/v0.3.0/ClassLive-0.3.0.apk)，在安卓手机上打开并安装。本次归档 APK 与 0.1.0 / 0.2.0 使用相同应用 ID 和签名，版本号已增加，可覆盖安装，保留原有密钥和课堂文字；不要先卸载旧版。系统若阻止，请按提示允许下载文件所用应用“安装未知应用”，安装完成后可以关闭该授权。GitHub Actions 自动生成的调试 APK 使用另一份签名，请选择这里归档的安装包。

使用实时转译前，打开 **设置** 填写自己的两项 API 密钥。本地收音测试无需密钥：

- AssemblyAI：https://www.assemblyai.com/dashboard
- DeepSeek：https://platform.deepseek.com/

已有上一版配置会保留。密钥只在手机里填写，不要发送到聊天或提交 GitHub。默认识别模型 `universal-streaming-english`；翻译模型 `deepseek-flash`。两个服务分别计费。

## 课堂操作

- **新课堂**：输入课程名；之前的课堂保留在记录中，不会清除。
- 点击顶部课程名：可修改名称。
- **开始听课 / 暂停听课**：连续识别英语，中文逐句显示。暂停会等待尾句，最多约 3.5 秒。长时间不停顿时约每 10 秒请求确认识别段。
- 底部显示正在识别的英文，以及收音状态、原始与输出强度、增益和实际麦克风输入模式。
- **课堂记录**：暂停后可以重新打开以前的课堂，继续听课、补译或生成 TXT。
- **补译未完成**：重试未翻译文字；翻译失败时英文仍保留。可翻页查看更早字幕并单句补译。
- **跟随**：自动跟随最新字幕；查看更早字幕会自动关闭跟随，可重新开启。

文字会自动保存在应用私有目录，下次打开恢复。不保存原始音频文件。

## TXT 仅在你需要时生成

1. 点击 **生成 TXT**。如果还在听课，会先暂停并保留尾句。
2. 选择 **英文＋中文**、**仅英文** 或 **仅中文**。
3. 如果存在未完成翻译，可以按当前内容生成，也可以稍后补译完再生成。
4. 在系统文件界面选择保存位置。

TXT 使用 UTF-8，包含课程名、开始时间、累计收音时长、每句时间及所选文字。未确认片段、识别低置信度片段和未完成翻译均标记。文件名示例：`Mission Design_20261002-1400_双语.txt`。

**暂停、退出、新建课堂都不会自动导出 TXT。**记录自动保存采用内部 JSON；只有点击生成后才准备文本快照并打开文件保存界面。导出后回到应用需要手动点击继续听课。

## 0.3.0 本地收音优化

- 每 100 ms 在本地检查能量、语音频段占比、过零率和音量变化，判断疑似讲话；不再等待云端返回文字才能启动增益。
- 增益上限 **12 dB（约 4 倍振幅）**，平滑提升和降低；实际增益受当前峰值限制，并非始终放大 4 倍。讲话结束后逐渐回到原始音量。
- 在疑似停顿期间更新背景估计，保留约 1.6 秒讲话尾部观察窗口，避免把连续讲课算成背景噪声。
- 突然大声时限制整个音频块的增益，平滑块边界；无法恢复麦克风已经产生的失真。
- 弱音提示依据**处理后的输出**，持续约 8 秒仍偏弱才提示。增强已有作用时显示“正在自动补偿”，不会仅因原始音量小而反复警告。
- **本地自动音量优化**默认开启；关闭后逐字节保留输入 PCM，仍显示监测提示。没有硬噪声门，不因疑似非语音而丢弃音频。
- 不自动启用系统 AGC。若发现系统增益已启用，则不叠加软件增益。
- **系统轻降噪**默认关闭，由你手动开启。只有手机支持并成功启用时才使用；若吞字可关闭。开启它不改变 API 模型。
- **麦克风输入模式**提供自动、标准麦克风和语音识别输入。自动与语音识别模式优先使用 VOICE_RECOGNITION；标准模式优先使用 MIC。初始化失败时回退到另一模式，实际模式显示在收音状态下方。回退只是兼容处理，并非自动选出最清楚的声音。

本地讲话判断采用轻量启发式算法，不是神经网络 VAD，也不识别谁在讲话。音乐或变化的噪声可能触发增益；极轻声可能无法触发。所有音频仍继续上传，不通过静音丢帧省费。数字增益会同时放大噪声，不能保证提高识别准确率。尚未集成 RNNoise / GTCRN；当前优先验证基础本地处理。

## 免费本地收音测试

1. 暂停实时收音，打开 **设置**，选择输入模式、音量优化和可选系统降噪。
2. 点击 **本地收音测试（15 秒，不调用 API）**。无需填写密钥，也无需先保存选项。
3. 点击开始，用老师讲话或同一段电脑播放的英语进行录制；保持手机位置、播放音量不变。
4. 分别点击 **回听原声** 和 **回听处理后声音**，比较轻声、句尾、噪声和失真。播放不额外归一化音量，两段取自同一次录制。
5. 返回设置，切换另一模式重复测试。选好后点击设置中的 **保存**，用于之后实时听课。

测试与实时听课使用同一个麦克风初始化和本地处理实现。这里的“原声”是 Android 音频输入送给应用的声音，可能已被手机系统处理。音频仅在测试页面内存中临时保留，不写文件、不上传；关闭测试页面后释放。切换应用或锁屏会停止录制和回听。收音不足 15 秒或中断时不保留半次测试。测试不生成 TXT、不调用任何识别或翻译 API。

## 保存、异常恢复与升级

- 已确认英文、中文返回及翻译错误都会保存；正在识别的英文约每秒保存一次。
- 突然退出或连接中断时，已收到但未确认的英文会保留为“未确认片段”。完全未传回的音频不能恢复。
- 翻译未完成后退出，下次打开可补译；不会将未完成条目当作成功。
- 旧版 `class.json` 迁移到“之前的课堂”，保留英文和中文，原文件保留。
- 写入采用 Android AtomicFile，通过单独线程按顺序保存；文件选择期间的 TXT 快照也可供应用被系统重建后继续保存。
- 当前版本仍是**前台收音**：切换应用或锁屏会暂停。断线后需手动继续，不做自动重连或音频回补。
- 麦克风和网络权限；密钥用 Android Keystore AES-GCM 加密。关闭应用备份。卸载会删除私有记录和配置。

## 开发与重建

标准 Android Java 工程。Java 17、Gradle 8.9、AGP 8.7.3、compile/target SDK 35，min SDK 26。无 Gradle Wrapper，可用本地 Gradle 配置 Android Studio；或使用 GitHub 工作流生成调试 APK。工作流生成的 APK 使用新调试签名，不能覆盖这里归档的 APK。

Linux 上使用本次已执行的构建方式：

```bash
python3 build_apk.py
python3 test_core.py
```

构建脚本从 app/build.gradle 读取版本号，按需下载官方 Android SDK 与 Maven Central 的 OkHttp/Okio；测试脚本另下载 org.json。产物在项目父目录。可设置 CLASSLIVE_BUILD_CACHE 指向现有构建缓存，以复用原签名。`.build-cache/debug.jks` 是本地调试签名，不包含 API 密钥，未加入源码包。重新生成签名会导致无法覆盖安装原 APK，需要先导出记录。不要把调试签名用于公开商店发行。

随附 GitHub 工作流可以构建并运行 Android lint；历史的 SDK tools 包错误及麦克风权限检查修复已保留。GitHub 自动构建与这里提供的本地签名归档 APK 是不同的安装包。
