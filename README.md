# ClassLive 课堂翻译 · Android 0.2.0

手机麦克风 → AssemblyAI 实时英语识别 → DeepSeek 中文翻译。Android 8.0 及以上。

## 安装

下载 [ClassLive-0.2.0.apk](releases/v0.2.0/ClassLive-0.2.0.apk)，在安卓手机上打开并安装。本次 APK 与上一版使用相同应用 ID 和签名，版本号已增加，可直接覆盖安装，保留原有密钥和课堂文字；不要先卸载旧版。系统若阻止，请按提示允许下载文件所用应用“安装未知应用”，安装完成后可以关闭该授权。

打开 **设置** 填写自己的两项 API 密钥：

- AssemblyAI：https://www.assemblyai.com/dashboard
- DeepSeek：https://platform.deepseek.com/

已有上一版配置会保留。密钥只在手机里填写，不要发送到聊天或提交 GitHub。默认识别模型 `universal-streaming-english`；翻译模型 `deepseek-flash`。两个服务分别计费。

## 课堂操作

- **新课堂**：输入课程名；之前的课堂保留在记录中，不会清除。
- 点击顶部课程名：可修改名称。
- **开始听课 / 暂停听课**：连续识别英语，中文逐句显示。暂停会等待尾句，最多约 3.5 秒。长时间不停顿时约每 10 秒请求确认识别段。
- 底部显示正在识别的英文，以及收音状态、输入强度和增益。
- **课堂记录**：暂停后可以重新打开以前的课堂，继续听课、补译或生成 TXT。
- **补译未完成**：重试未翻译文字；翻译失败时英文仍保留。可翻页查看更早字幕并单句补译。
- **跟随**：自动跟随最新字幕；查看更早字幕会自动关闭跟随，可重新开启。

文字会自动保存在应用私有目录，下次打开恢复。不保存原始音频文件。

## TXT 仅在你需要时生成

1. 点击 **生成 TXT**。如果还在听课，会先暂停并保留尾句。
2. 选择 **英文＋中文**、**仅英文** 或 **仅中文**。
3. 如果存在未完成翻译，可以按当前内容生成，也可以稍后补译完再生成。
4. 在系统文件界面选择保存位置。

TXT 使用 UTF-8，包含课程名、开始时间、累计收音时长、每句时间及所选文字。未确认片段、识别低置信度片段和未完成翻译均标记。文件名示例：`Mission Design_20261002-1400_双语.txt`。

**暂停、退出、新建课堂都不会自动导出 TXT。**记录自动保存采用内部 JSON；只有点击生成后才准备文本快照并打开文件保存界面。导出后回到应用需要手动点击继续听课。

## 默认收音优化：温和、可关闭

- 每 100 ms 检查输入强度、峰值及短时背景水平。
- 增益最多提升 **6 dB**；只在近期有识别反馈、且输入高于估计背景时缓慢补偿。静音和没有识别反馈的背景声音不会触发主动增益提升。
- 突然大声时检查整个音频块的峰值，限制软件放大引入的新削波；无法恢复麦克风已经录坏的失真声音。
- 持续弱收音、持续失真、疑似较强背景声或持续零输入时，显示建议；单次撞击和短暂停顿不会立即触发这些警告。
- **温和音量优化**默认开启；关闭后不做软件增益调整，仍显示监测提示。
- 不自动启用系统 AGC。若发现系统增益已启用，则不叠加软件增益。
- **系统轻降噪**默认关闭，由你手动开启。只有手机支持并成功启用时才使用；若吞字可关闭。开启它不改变 API 模型。
- 不使用强降噪、人声分离、硬噪声门或自动切换收费模型。

背景水平和收音提示是估计，不能据此确定谁在讲话或麦克风被什么遮挡。手机到老师的距离、回声、多人讲话和手机自身处理都会影响识别；默认处理并非保证提高清晰度。先试约 30 秒英语，观察字幕与提示，必要时关闭温和优化。

## 保存、异常恢复与升级

- 已确认英文、中文返回及翻译错误都会保存；正在识别的英文约每秒保存一次。
- 突然退出或连接中断时，已收到但未确认的英文会保留为“未确认片段”。完全未传回的音频不能恢复。
- 翻译未完成后退出，下次打开可补译；不会将未完成条目当作成功。
- 旧版 `class.json` 迁移到“之前的课堂”，保留英文和中文，原文件保留。
- 写入采用 Android AtomicFile，通过单独线程按顺序保存；文件选择期间的 TXT 快照也可供应用被系统重建后继续保存。
- 当前版本仍是**前台收音**：切换应用或锁屏会暂停。断线后需手动继续，不做自动重连或音频回补。
- 麦克风和网络权限；密钥用 Android Keystore AES-GCM 加密。关闭应用备份。卸载会删除私有记录和配置。

## 开发与重建

标准 Android Java 工程。Java 17、Gradle 8.9、AGP 8.7.3、compile/target SDK 35，min SDK 26。无 Gradle Wrapper，可用本地 Gradle 配置 Android Studio；或使用 GitHub 工作流生成调试 APK。工作流生成的 APK 使用新调试签名，不能覆盖这里归档的 APK。

Linux 上使用本次已执行的构建方式：

```bash
python3 build_apk.py
python3 test_core.py
```

构建脚本按需下载官方 Android SDK 与 Maven Central 的 OkHttp/Okio；测试脚本另下载 org.json。产物在项目父目录。`.build-cache/debug.jks` 是本地调试签名，不包含 API 密钥，未加入源码包。重新生成签名会导致无法覆盖安装原 APK，需要先导出记录。不要把调试签名用于公开商店发行。

随附 GitHub 工作流可以构建并运行 Android lint，该工作流本次未执行。
