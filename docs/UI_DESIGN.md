# ClassLive 1.0 UI

变体：nightshift / 自定义薄荷绿 #B8F5CC / 炭黑 #141615 / 8dp 切角 / 无底纹 / 标准阅读密度 / 静态反馈。
主视觉：真实课堂文本、时间戳、翻译计数和模型存储。
页面类型：听课、记录、设置均以阅读为主。

统一资源位于 EndfieldUi.java。拉丁标签打包 Saira 可变字体（OFL），中文使用系统黑体。正文直角、操作按钮切角；无投影、装饰性循环、渐变或游戏素材。删除操作使用单独的红色。主操作及当前导航使用薄荷绿填充，墨色文字。

听课：上方课堂名和操作入口，中间可滚动字幕，下方独立测量的听课状态及开始/暂停按钮，最底部主导航。翻译字体 19sp，英文 15sp。字幕内容和视口高度变化均触发跟随，不使用抢焦点的 fullScroll。用户滑动回看关闭跟随；手动打开跟随恢复最后 100 条窗口。

设置：模型 / 翻译 / 收音 / 术语 / 关于。翻译与收音分别编辑，保存时保留其他项。模型页面展示状态、下载体积和量化取舍；切换和删除仅允许识别与尾句处理结束后。

默认只提供深色主题，符合本次用户偏好。所有操作目标至少 48dp，当前导航同时标记 selected 和无障碍描述。不添加动画，因此系统移除动画不会损失状态或内容。

安装方案：独立包名 com.yeezi.classlive.v1，保留旧测试版及其课堂记录。两版数据相互独立。
